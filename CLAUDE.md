# Сайт и приложение детской клиники «Колибри» (Крым, с. Мирное)

Пользователь — маркетолог, пишет по-русски, не программист, просит делать всё самому и показывать результат.
Клиент — детская клиника «Колибри»: с. Мирное, Симферопольский р-н, ул. Крымской Весны, 9к1, тел. +7 (978) 130-00-30,
домен kolibri.clinic (пока не используется). Референс дизайна — https://www.clinic23.ru.

## Где что лежит
- Сайт (эта папка): 8 страниц `*.html`, стили `css/style.css`, данные `js/data.js` (телефон, адрес, часы, врачи,
  направления, УЗИ, цены, статьи, отзывы), фото `js/photos.js` + файлы `img/photos/*.jpg`, скрипт `js/main.js`
  (шапка, подвал, слайдер, карточки, модалки, загрузка фото), `js/rostomer.js` (макеты ростомера).
- Концепция приложения — `app-concept.html` (20 экранов, таблица функций, схема связи с МИС).
- Ростомер на пеленальный столик — `rostomer.html`, файлы для печати в `ростомер/` (SVG, PNG 300 dpi, PDF с вылетами).
- Инструкция для клиента и разработчика — `ПРОЧТИ-МЕНЯ.txt`.
- Материалы клиента: `C:\Users\user\Downloads\Маша\` (брендбук, логотипы), фото в `Downloads\Маша\Сайт\` и
  `Downloads\Маша\фото для сайта\` (обработанные — в `обработанные\`, баннеры — в `Сайт\баннеры\`).
- Цветокоррекция: `C:\Users\user\Documents\Meta-Bitrix\цветокор\рецепт-колибри.ps1` (единый мягкий фильтр: автобаланс,
  кожа без красноты, приподнятый чёрный) и `resize-web.ps1`. Числа для PowerShell форматировать через InvariantCulture
  (русская локаль пишет «0,93» и ломает разбор). `.ps1` с кириллицей — только UTF-8 с BOM.

## Публикация
Сайт живёт на GitHub Pages: https://vetaliytsepelev-pixel.github.io/kolibri-site/ (репозиторий
github.com/vetaliytsepelev-pixel/kolibri-site, аккаунт пользователя, вход в GitHub он делает сам).
Любое изменение выкладывать командой из этой папки: `bash tools/publish.sh "что сделано"` — скрипт копирует файлы
в git-копию, ставит номер версии в адреса css/js/фото (иначе браузер 10 минут показывает старое), коммитит и пушит.
Git-копия: `%TEMP%\claude\...\scratchpad\kolibri-site` (путь в `tools/publish.sh`, переменная KOLIBRI_REPO); если её нет —
`git clone` репозитория туда или в любую папку и поправить путь.
Локальный просмотр: `node tools/serve.js` → http://localhost:8765 (в `.claude/launch.json` проекта Meta-Bitrix есть
конфигурация `kolibri-site`).

## Дизайн и договорённости
- Брендбук: цвета #7638B0, #67378A, #2E1B5B, #CDBBE3; шрифт Comfortaa (заголовки) + Nunito (текст), оба OFL с Google Fonts.
- Слайдер на главной и баннеры страниц: фото во всю правую часть, растворяется в градиент маской (`mask-image`),
  никаких цветных подложек и стыков. Карточки услуг и направлений — иконки, без фото; при наведении плитка иконки
  становится фиолетовой, карточка приподнимается.
- Режим работы: пн–пт 08:00–19:00, сб 08:00–17:00, вс выходной (от клиента 01.10.2026).
- Фото: все снимки на сайте прогонять через `рецепт-колибри.ps1`, чтобы гамма была единой; слайдер и баннеры —
  настоящие фото клиента. ИИ-генератор image.pollinations.ai с 01.10.2026 платный (ответ 402) — новые ИИ-картинки
  делать нечем; остались только ранее сгенерированные портреты врачей и интерьеры (заглушки до фото клиента).
- Баннеры страниц (решение пользователя 01.10.2026): фото клиента на баннерах повторяли уже использованные — не
  годится. Новые фото генерирует сам пользователь в Gemini по нашим промтам: `Downloads\Маша\Сайт\gemini\ПРОМТЫ.txt`
  (7 сцен, туда же кладёт картинки; Gemini может сохранить их и в «Загрузки» как Gemini_Generated_Image_*).
  Стиль серии как у clinic23: студийное фото на ровном фиолетовом фоне в цвет баннера (~#7F44BA), свет слева сверху,
  одежда белая/кремовая/лавандовая, фирменный образ — маленькая фиолетовая колибри в каждом кадре, 16:9, человек
  справа, левые 40 % пустые. Сначала №1 «Врачи» → ставлю на баннер и показываю → остальные в том же чате Gemini
  с фото №1 как образцом. При обработке НЕ гонять автобаланс белого из рецепта: он «нейтрализует» фиолетовый фон;
  фон подгонять под градиент баннера (--p700 → --p500).
  Сделано 01.10.2026: пользователь сгенерировал все 7 сразу (`Downloads\Маша\фото для сайта\Банера`, 2400×1792),
  исходники по ключам — `Сайт\баннеры-gemini\исходники\`, обработка — `Meta-Bitrix\цветокор\баннеры-gemini.ps1`
  (лампа в углу у ban-uzi и ban-poleznoe → угол заменяется ровным фоном; насыщенность фиолетового фона 0,44–0,56
  поднимается до цвета баннера #743aac, S 0,66 / V 0,675, кожу и светлую одежду не трогает) → `обработанные\` и
  img/photos (1600 px). Баннер: `object-position: center top`, чтобы не резало головы. Превью — headless Edge
  (`msedge --headless=new --screenshot --window-size=1366,640`); уже ~500 px он не умеет, телефон смотреть в Browser.
- Отзывы на главной — примеры; тексты врачей — только из docx клиента, ничего не выдумывать.

## Приложение и МЕДМИС
- МИС клиники — МЕДМИС, облако https://app10.medmis.ru (логин/пароль/код клиники вводит пользователь сам, пароли не вводить).
- База знаний МЕДМИС https://confluence.medmis.ru: разделы «Интеграции → Онлайн-запись/Виджет/Документация» закрыты,
  нужен вход или запрос в support@medmis.ru. У МЕДМИС есть виджет онлайн-записи и своё брендированное приложение
  пациента (запись, семья, анализы, заключения, push).
- Референс приложения — видео https://youtu.be/jMto1vS-2Sg (приложение «Клиника Екатерининская»): вход по телефону
  и коду, семейные профили, главная с баннерами, запись услуга/специалист/дата, анализы с PDF, записи, цены, контакты.
  Наша концепция повторяет это + чат с врачом, прививки, программы наблюдения. План: сначала виджет и готовое
  приложение МЕДМИС, параллельно запросить API для своего приложения.
